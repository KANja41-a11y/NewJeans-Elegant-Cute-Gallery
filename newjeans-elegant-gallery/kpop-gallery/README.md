# NewJeans Elegant Cute Gallery

Gallery NewJeans tema **Elegant + Cute**  
Siap langsung di-upload ke **GitHub Pages**.

## Fitur
- Foto member resmi (Minji, Hanni, Danielle, Haerin, Hyein)
- Foto group (Ditto Era, OMG Era, My Love Concept, dll)
- Cover album (New Jeans, OMG, Ditto, Get Up, How Sweet, Supernatural)
- Lagu **Ditto** sudah terpasang (Play / Pause + volume)
- Kursor kelinci 🐰
- Animasi soft & elegant

## Cara Upload ke GitHub Pages

1. Extract zip
2. Buat repository baru di GitHub (Public)
3. Upload **semua isi folder** ini (index.html, style.css, script.js, ditto.mp3, folder images/)
4. Settings → Pages → Deploy from branch `main` → `/ (root)`
5. Tunggu 1-2 menit → website live

Tidak perlu Chrome atau aplikasi lain. Cukup browser biasa.
